# Экран входа Glazza

Вход оформлен по согласованному графитово-лаймовому макету: глаз-диафрагма, фирменная композиция и настоящая HTML-форма поверх отдельного декоративного изображения.

- `app/static/login.css` ограничен экраном `#login`; рабочая панель сохраняет прежнюю тему.
- `login.js` переводит только экран входа RU/KZ, сохраняет лишь выбранный язык в localStorage и управляет видимостью пароля. Учётные данные и токены туда не записываются.
- Пароль скрывается после входа и при возврате на экран авторизации. Поле очищается после успешного входа.
- Во время запроса блокируется именно submit-кнопка и предотвращается повторная отправка. Ошибка доступна экранному диктору.
- Текст о защищённом подключении показывается только при HTTPS; на HTTP отображается нейтральное описание локальной системы.
- Декоративный фон хранится локально в WebP, около 96 КБ; внешние шрифты и CDN не нужны. На мобильном экране используется вертикальная композиция. Учитывается prefers-reduced-motion.
- Серверный API входа, cookie, CSRF и срок сессии не менялись. CSP не ослаблена.

Браузерная проверка: `python tests/browser_login.py`. Проверяет ширины 320, 390, 768, 1024 и 1672 px, RU/KZ, показ/скрытие пароля, локализованную ошибку, двойную отправку, вход по Enter, сессию и выход, отсутствие JS-ошибок и сохранение темы рабочей панели. Скриншоты для локальной визуальной проверки включаются отдельно переменной `GLAZZA_LOGIN_SCREENSHOTS`; CI их не создаёт.
