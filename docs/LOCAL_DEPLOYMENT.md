## Доступ

- HTTPS-панель с веб-камерой: https://192.168.1.18:8443.
- Панель Glazza в локальной сети: http://192.168.1.18:8082.
- Панель на самом сервере: http://localhost:8082.
- Frigate: https://localhost:8971, отдельная авторизация и локальный сертификат.
- Логины и пароли: `credentials.txt` в корне проекта, доступ только владельцу файла.

Порт Glazza изменён на 8082, поскольку 8080 уже занят другим приложением.
Он задаётся переменной `GLAZZA_PORT` в `.env`; стандартное значение — 8080.
Локальный `compose.override.yaml` также публикует панель на сетевом адресе
`192.168.1.18`. Авторизация обязательна. Frigate доступен на самом сервере.
Для доступа через SSH-туннель:

```bash
ssh -L 8082:127.0.0.1:8082 -L 8971:127.0.0.1:8971 user@server
```

## Управление

Из корня проекта:

```bash
# Запустить все сервисы; контейнеры также перезапускаются Docker автоматически
docker compose --profile nvr --profile ai up -d

# Состояние
docker compose --profile nvr --profile ai ps

# Последние сообщения
docker compose --profile nvr --profile ai logs --tail=100

# Пересобрать после изменения исходников
docker compose --profile nvr --profile ai up -d --build

# Остановить; локальные данные сохранятся
docker compose --profile nvr --profile ai down

# Создать резервную копию настроек и базы
python3 scripts/backup.py --data data
```

В этой сети загрузка PyTorch требует доверенного CA сетевого шлюза.
Локальный `compose.override.yaml` передаёт `/etc/ssl/certs/ca-certificates.crt`
в сборку анализатора через BuildKit secret `pip_ca_bundle`.
Проверка TLS включена; bundle не копируется в образ.
На другом компьютере этот override можно убрать, если дополнительный CA не нужен.

## Видеоанализ и камеры

Установлены проверенные по SHA-256 веса VD-MIL / MoViNet-A0 и MediaPipe Face Landmarker.
Анализатор использует CPU, согласно базовой конфигурации проекта.
Для распознавания возможной кражи нужен отдельный официальный checkpoint VadCLIP;
без него этот вид анализа недоступен.

Рабочий режим включён без демонстрационных событий. Камеры добавляются в панели
по RTSP-адресу; после добавления нужно применить настройки Frigate.
Порядок подключения описан в [README](../README.md) и [инструкции пилота](COLLEGE.md).

Данные и конфигурация находятся в `data/`, `config/`, `media/`, `models/`.
Файлы `.env`, `credentials.txt` и локальный Compose override не отслеживаются Git.
