# Карта Казахстана

В разделе **«Карта Казахстана»** отображаются все камеры, добавленные в Glazza.
Камеры с координатами показаны отметками, остальные находятся в списке
**«Без координат»**. Публичные камеры автоматически не подключаются.

1. Подключите камеру в разделе «Камеры» или кнопкой над картой.
2. Выберите камеру в списке карты.
3. Нажмите на нужное место либо введите широту и долготу в десятичных градусах.
4. Нажмите **«Сохранить отметку»**. Перезапуск Frigate не нужен.

Отметка открывает название камеры и переход к её кадру и настройкам зон.
Кнопка **«Все отметки»** подбирает масштаб по расположению камер,
**«Весь Казахстан»** возвращает исходный обзор страны. Поиск фильтрует список
по названию и идентификатору. **«Убрать отметку»** очищает координаты, сохраняя
камеру и её видеопоток. Наличие отметки не означает, что камера сейчас передаёт видео.

Координаты хранятся в локальной SQLite-базе; существующая база обновляется
автоматически. `PUT /api/cameras/{id}/location` принимает `latitude` и `longitude`
(оба числа или оба `null`), требует авторизацию и CSRF. Редактирование подключения
через старый API без координат сохраняет ранее указанное расположение.

Leaflet 1.9.4 и его BSD-2-Clause лицензия находятся в `app/static/vendor/leaflet`.
Подложка загружается браузером с `https://tile.openstreetmap.org`, требует интернета
и использует обычный браузерный кеш. При недоступности подложки список и ввод
координат продолжают работать. Названия камер, видеопотоки и пароли не отправляются
поставщику карты; запросы участков карты отражают просматриваемую область.
Атрибуция видна на карте. Для запросов изображений используется
`strict-origin-when-cross-origin`, остальные ресурсы сохраняют `same-origin`.

Источники: [Leaflet](https://leafletjs.com/),
[правила использования подложки OpenStreetMap](https://operations.osmfoundation.org/policies/tiles/).
