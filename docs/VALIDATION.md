## Что не проверено

- Полный `docker compose up` и сборка Docker-образов: Docker Engine отсутствовал в среде разработки. Проверка конфигурации и сборка API-образа добавлены в GitHub Actions; локальный отчёт не является отчётом CI.
- Физическая IP-камера, RTSP, запись и архив Frigate. Контракт опроса / клипов проверялся с HTTP fixtures, конфигурация сверена с исходниками Frigate v0.18.2.
- Реальные веса VadCLIP и классификация драки / кражи: официальная ссылка OneDrive вернула HTTP 403. Есть адаптер и установщик, но реального inference этой модели в проверке нет.
- Соответствие метрикам статьи VadCLIP, precision / recall на объекте, ложные тревоги на камеру-час, throughput, p95 latency, GPU, многосуточная работа.
- Полное аварийное восстановление NVR с архивом: проверена только SQLite backup-копия.

**Статус: пригодно для установки и технического пилота с явными ограничениями; промышленная приёмка не пройдена.**
